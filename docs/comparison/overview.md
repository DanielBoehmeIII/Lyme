## When to Choose Lyme

- You want **observability** — traces, evidence, replay
- You care about **measurement** — not just task completion
- You need **local-first** — code never leaves your machine
- You want a **daily workflow** — dashboard, inbox, branch review
- You're evaluating **agent performance** scientifically

## When Not to Choose Lyme

- You need the **most powerful coding agent** (Claude Code is stronger)
- You want the **simplest possible tool** (Aider is more straightforward)
- You need a **lightweight agent** (OpenCode is more minimal)
- You don't care about **measurement or observability**

## Lyme's Unique Strengths

1. **Evidence-grounded Q&A** — answers come with file citations and confidence scores
2. **Dogfood testing** — Lyme runs against itself and sibling repos automatically
3. **Metric provenance** — every metric knows where it came from and whether it's real
4. **Daily developer workflow** — dashboard, start, inbox, diff-explain, branch-review
5. **Research platform** — built-in experiment design, ablation studies, scaling laws
