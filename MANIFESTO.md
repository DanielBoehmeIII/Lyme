# Lyme Manifesto

**Lyme is the operating system for autonomous local software engineering.**

---

## The Vision

Local coding agents are a platform play, not a feature. The company that makes local agents dependable will define the category. Lyme is that infrastructure.

## The Principles

1. **LOCAL IS THE FUTURE** — The best coding agent runs on your hardware, under your control, with zero data leaving your machine.

2. **RELIABILITY OVER NOVELTY** — A coding agent that works 95% of the time is worth more than one that is 10% more creative but fails unpredictably.

3. **ORCHESTRATION IS THE MOAT** — Models improve monthly. The moat is the system that orchestrates models, plans edits, runs tests, repairs failures, and learns from every session.

4. **DEVELOPERS DESERVE AUTONOMY** — Lyme amplifies developers by handling mechanical software engineering, freeing them for architecture, design, and judgment.

5. **MEASURE EVERYTHING** — Every edit is scored. Every failure is categorized. Every session improves the system.

6. **OPEN ECOSYSTEM** — Plugin SDK, agent configs, and evaluation harness are designed for extensibility.

## What Lyme Is

Lyme is a complete platform for autonomous local software engineering:
- **8-layer architecture** separating orchestration, inference, planning, memory, validation, execution, training, and UI
- **Multi-agent society** with trust-weighted collective intelligence
- **Local model runtime** supporting Ollama, llama.cpp, vLLM, and Transformers
- **Repo intelligence** with AST parsing, dependency graphing, and semantic search
- **Self-recovery** with failure detection, rollback snapshots, and confidence scoring
- **Plugin ecosystem** for custom agents, tools, workflows, and model packs
- **Enterprise features** including airgapped mode, audit trails, and RBAC
